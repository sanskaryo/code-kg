💡 Button & Feature Overview

  • Scan Local Folder: Indexes and parses all C++, Java, Python source files in the entered directory path into graph nodes.
  • Search Code: Performs semantic search across functions, classes, and code logic.
  • Rescan Repo: Re-indexes the default test repository.
  • Check Cycles: Finds circular dependency loops in code and highlights affected nodes in Yellow.
  • Blast Radius: Highlights all upstream caller functions impacted by changing a node in Red.
  • Export SVG / Download Diagram: Downloads the current interactive graph diagram as an SVG vector image.
  • Entity Checkboxes: Toggle visibility of Modules, Classes, Functions, Imports, or Call edges.
  • Canvas Navigation: Click & drag background to pan, scroll wheel or +/- buttons to zoom, click any node to view source code.
